# Lally Editorial Boutique

LALLY BOUTIQUE — PREMIUM FASHION E-COMMERCE WEBSITE

Создай полноценный трёхстраничный двуязычный сайт для женского бутика одежды LALLY BOUTIQUE в Баку, Азербайджан.

ВАЖНО: Используй два загруженных изображения как визуальные референсы. Не копируй чужой бренд или сайт. Создай оригинальный дизайн, вдохновлённый их эстетикой.

1. ОБЩАЯ КОНЦЕПЦИЯ И ДИЗАЙН

Стиль: High Fashion Editorial, Avant-garde Fashion, Luxury Boutique.

Сайт должен выглядеть как интернет-представительство современного европейского fashion-бренда, а не как стандартный интернет-магазин из готового конструктора.

Визуальные особенности:

- Крупная элегантная типографика.
- Необычная журнальная композиция.
- Эффектные фотографии моделей.
- Контрастные сочетания светлого и тёмного.
- Чёрный, белый, графитовый, молочный и серебристый цвета.
- Минимум декоративных элементов.
- Плавные анимации и переходы.
- Бегущие текстовые строки.
- Параллакс-эффекты при прокрутке.
- Адаптация под смартфоны и компьютеры.

Не использовать стандартные карточки товаров с толстыми рамками, тяжёлые тени, шаблонные градиенты и перегруженные элементы.

Сайт должен быть быстрым и визуально выразительным.

2. ДВУЯЗЫЧНОСТЬ

Сайт должен поддерживать два языка:

- Русский (RU).
- Азербайджанский (AZ).

В верхнем меню разместить переключатель RU / AZ.

При переключении языка должны меняться все тексты, меню, описания товаров, акции, контактные подписи и готовые сообщения WhatsApp.

Выбор языка должен сохраняться при переходе между страницами.

Азербайджанский язык должен быть полноценным, с правильными буквами ə, ı, ö, ü, ç, ş, ğ.

4. СТРАНИЦА №2 — КАТАЛОГ ОДЕЖДЫ

Это самая важная страница сайта.

Каталог должен иметь редакционный fashion-дизайн, вдохновлённый вторым загруженным изображением.

Категории:

- Платья.
- Костюмы.
- Повседневная одежда.
- Вечерняя одежда.
- Новинки.

ВАЖНО: Товары я буду самостоятельно добавлять непосредственно через редактор проекта. Поэтому создай удобную и понятную структуру каталога, чтобы я мог добавлять новые товары без необходимости переписывать код.

Каждый товар должен содержать:

- Фотографию товара в PNG с прозрачным фоном.
- Название.
- Краткое описание.
- Артикул.
- Размеры S, M, L, XL (индивидуально для каждого товара).
- Старую цену.
- Новую цену со скидкой.

Ценовой диапазон: 100–200 AZN.

Дизайн отображения товаров:

Не использовать обычные прямоугольные карточки интернет-магазина.

Платье должно визуально находиться непосредственно на фоне страницы, без рамок и подложек. Использовать фотографии PNG с прозрачным фоном, чтобы создавался эффект парящего предмета.

Фотографии должны быть крупными, яркими, сочными и качественными.

При наведении курсора на товар предусмотреть лёгкую анимацию увеличения.

При нажатии на платье открывать красивое увеличенное представление товара в отдельном полноэкранном или крупном модальном окне.

В этом окне показать:

- Большую фотографию платья.
- Название модели.
- Краткое описание.
- Артикул.
- Выбор доступного размера.
- Старую цену, зачёркнутую.
- Новую цену, визуально выделенную.
- Размер скидки в процентах.
- Кнопку «Заказать через WhatsApp».

Например:

Платье «Коктейль Шанель»
Артикул: LB-001
Размеры: S / M / L
Старая цена: 180 AZN
Цена со скидкой: 145 AZN.

После выбора размера кнопка WhatsApp должна автоматически формировать готовое сообщение.

Для русского языка:

«Здравствуйте! Хочу заказать платье "Коктейль Шанель", артикул LB-001, размер L. Подскажите, пожалуйста, доступно ли оно для заказа?»

Для азербайджанского языка:

«Salam! "Kokteyl Şanel" donunu sifariş etmək istəyirəm. Artikül: LB-001, ölçü: L. Zəhmət olmasa, sifariş üçün mövcud olub-olmadığını bildirin.»

Номер WhatsApp:
994706520292.

Использовать прямые ссылки WhatsApp с автоматически подставленным и корректно закодированным текстом.

Также предусмотреть кнопку WhatsApp непосредственно на каждой товарной позиции.

6. АНИМАЦИИ И ЭФФЕКТЫ

Реализовать:

- Плавный параллакс при прокрутке.
- Плавное появление изображений.
- Эффект увеличения фотографий при наведении.
- Анимированные переходы между страницами.
- Плавное перемещение к разделам.
- Бегущую строку.
- Эффект появления текста при загрузке главной страницы.

Анимации должны быть элегантными, без чрезмерных эффектов.

На смартфонах использовать облегчённые версии анимаций, чтобы сайт работал быстро.

Учитывать системную настройку уменьшения движения (prefers-reduced-motion).

7. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

Создать три отдельные страницы с полноценной навигацией:

/ — главная.
/catalog — каталог.
/about — о бутике.

Использовать современный адаптивный frontend.

Создать отдельный файл или модуль с данными товаров, чтобы добавление новых платьев было максимально простым.

Предусмотреть демонстрационные товары, которые впоследствии я заменю собственными фотографиями, названиями и ценами.

Все кнопки должны работать.

Все ссылки WhatsApp должны открываться с готовым текстом на выбранном языке.

Не создавать неработающие кнопки и фиктивные формы.

Не добавлять онлайн-оплату, регистрацию и личный кабинет.

Сделать сайт готовым к бесплатному тестовому размещению.

В первую очередь создать законченный визуальный дизайн и работающую структуру всех трёх страниц.

После создания проверь мобильную версию, навигацию, переключение языков, выбор размеров и формирование WhatsApp-сообщений.

Главный результат: LALLY BOUTIQUE должен выглядеть как настоящий премиальный fashion-бренд с авторской эстетикой, а не как обычный шаблонный магазин одежды.
